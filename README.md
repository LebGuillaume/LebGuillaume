# Salut, je m'appelle Guillaume 👋

Développeur web freelance (micro-entrepreneur), basé à Pont-à-Marcq (Hauts-de-France).
Je construis des sites et applications sur-mesure — avec une spécialisation en cours sur le secteur agricole et maraîcher, en lien avec mon propre parcours en maraîchage.

## 🌾 Spécialisation

Avant le dev, j'ai travaillé en maraîchage. Ça change la façon dont j'aborde les projets pour les producteurs en vente directe : je comprends leurs contraintes (saisonnalité, vente sur site, gestion des commandes) sans avoir à me les faire expliquer.
Je code aussi mes propres outils pour ce secteur (MaraîchPlan), en parallèle des projets clients (La Terre Avant Tout, Bio'Cense).
